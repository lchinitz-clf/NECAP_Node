Advanced settings

Controls how this document is split into blocks for searching.

ⓘ Smaller blocks help find precise matches but include less surrounding context; overlap repeats a few words at the start of the next block so a sentence split across the boundary isn't lost. In practice, raising this much past 300-400 words usually won't make blocks bigger — only lowering it will have much effect.
