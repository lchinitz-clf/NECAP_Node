New England Climate Adaptation Policy (NECAP) Data Portal

The goal of the New England Climate Adaptation Policy (NECAP) Data Portal is to provide accurate, up-to-date information on climate adaptation polices in New England.

The portal has a structured database of approximately 900 policy initiatives drawn from state-level climate adaptation, coastal resilience and hazard mitigation plans; a chatbot to interact with the policy data; and a system to accelerate the evaluation of climate adaptation plans using sets of critical questions curated by experts from the Conservation Law Foundation.

What each tab does

The menu in the top right (☰) switches between these:

  1. Document Management. Work happens inside a named "area" — type an existing area's name to open it (for example, the area holding the ~900-initiative policy database), or type a new name to start one and import your own PDF, Word, or text documents into it. Every document is automatically split into smaller, searchable blocks on import.
  2. Rubric Control. This is where the Conservation Law Foundation's critical questions live, organized into named topics (for example, one topic per policy area). Each topic is a list of attributes — a question or expectation, paired with what an ideal answer looks like. Browsing here shows you what each topic actually checks for; you'd only add or edit a topic yourself if you have a new set of questions to apply.
  3. Query and Response. The chatbot itself. Pick the same area you opened in Document Management, then either type a question in plain language, or pick a topic from the "Compare against an ideal proposal" dropdown to have every document in the area evaluated against that topic's questions, one attribute at a time. Either way, the answer links back to the exact block(s) of text it was drawn from — click a citation to see it in context.
  4. Logs. A record of past questions and actions, in case you need to revisit what was asked, or by whom.

Using it for the first time

  1. Open Document Management and enter the name of the area you want to work in.
  2. If it's a new area, import the documents you want to ask questions about. If you're using the existing policy database, you can skip straight to the next step.
  3. Switch to Query and Response, confirm the same area is still selected, and either ask a question or pick a rubric topic to run a full comparison.
  4. Read the answer and check its citations. For a longer comparison run across many attributes, consider turning on the email notification under Advanced settings so you don't have to keep the tab open and watch it finish.

This page is just background reading — nothing on it is interactive. Use the menu above to get to the rest of the portal.
